TaskFlow AI, deployed as OpsPilot

Python, Flask, SQLite, Anthropic Claude API, Pydantic, JavaScript

An AI operations tool built after I saw how much time a solar company was losing to manual work. It finds which workflow steps AI can automate and which still need a person, and a built-in assistant answers questions from the company’s own data.   • Guarded: a person approves every change, and legal, money, and urgent issues go straight to human review.

NYC 311 service request analysis

Python, PostgreSQL, SQL, pandas, scikit-learn, Streamlit

An analysis of 3.66 million public NYC 311 requests: how long each city agency takes to close them, and which requests will close within a week.

  • Loaded: a resumable pipeline pulls the data day by day, retries failures, and loads all 3.66M rows into PostgreSQL in 94 seconds.
  • Checked: row counts are reconciled at every stage, and the dashboard is validated against SQL with 35 tests.
  • Predicted: a model trained only on past data predicts 7-day closure at 0.956 ROC AUC, against a 0.50 baseline.

IT support ticket classifier

Python, scikit-learn, pandas, NumPy, Streamlit

A model that reads an IT support ticket and routes it to one of 8 categories, trained on 47,837 labeled tickets.

  • Found: 1,639 clusters of near-duplicate tickets that would have leaked answers from training into testing.
  • Fixed: grouped duplicates together so the test set is truly unseen.
  • Checked: 0.865 macro F1 on 6,959 held-out tickets, at least 0.84 recall in every category, and 24 automated tests.
